Thèmes alignés sur Lichess (`SoundSet`) : Silent, Standard, Piano, NES, SFX, Futuristic, Lisp, Woodland, Robot, Music (pentatonique).

Packs supplémentaires AFRICHESS (échantillons Lichess `other` / instruments, ou synthèse) :
Guitar, Energy, Crystal, Drums, Glass, Brass, Retro.

Thème **Arena** — son de mat original (boom + accord ascendant), dans l’esprit d’une fin de partie dramatique. Ce n’est pas un asset Chess.com (propriétaire).

Fichiers par thème : `public/sounds/themes/<theme>/{move,capture,castle,check,checkmate}.{mp3,ogg}`

| Événement | Fichier Lichess typique |
|-----------|-------------------------|
| move | `Move` |
| capture | `Capture` |
| castle | `Castles` (sinon `Move`) |
| check | `Check` |
| checkmate | `Checkmate` / `Victory` / swells |
